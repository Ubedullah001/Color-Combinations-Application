🎨 ColorLab

ColorLab is a simple web application made with Python and Streamlit.

It helps users explore RGB primary colors and create different colors by changing LAB values.

Features

- Shows primary RGB colors:
  - Red
  - Green
  - Blue
- Allows users to change L*, a*, and b* values.
- Generates the selected LAB color.
- Shows the generated color.
- Shows RGB values.
- Shows HEX color code.

Technologies

- Python
- Streamlit
- NumPy
- Scikit-image
- GitHub

Project Files

- "app.py" — Main application
- "requirements.txt" — Required Python libraries
- "README.md" — Project information

Run the App

Install the required libraries:

pip install -r requirements.txt

Run the application:

streamlit run app.py

Deployment

Upload these files to a GitHub repository and deploy the project using Streamlit Community Cloud.

Purpose

This application is designed as a simple color exploration tool, especially useful for students learning about RGB and LAB color systems.
